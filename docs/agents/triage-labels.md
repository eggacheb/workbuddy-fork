# Triage Labels

这些技能用五个规范分诊角色说话。这个文件把角色映射到本仓库 issue tracker 里实际用的标签字符串。

| 角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者先评估 |
| `needs-info` | `needs-info` | 等报告人补信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整,AFK agent 可直接开工 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不打算处理 |

技能提到某个角色时(例如「打上 AFK-ready 分诊标签」),用上表「本仓库的标签」那一列的字符串。

要换词汇就改中间那列,别改第一列。
